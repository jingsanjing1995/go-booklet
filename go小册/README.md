# Go 小册

一份面向自学的 Go 手册：从语法入门走到并发、工程化和运行时原理。

目标读者：

- 有任意一门语言基础，想系统学 Go
- 已经写过一点 Go，但接口、并发、模块、测试还不扎实
- 准备面试或读源码前，想把「为什么这样设计」补齐

建议环境：**Go 1.22+**（文中会标出 1.18 泛型、1.20 错误包装、1.21+ `clear`/`min`/`max`、1.22 `range` 整数等较新特性）。

---

## 怎么用这份小册

1. **先读后敲**：每章都有完整可编译片段，不要只看结论。
2. **对照示例**：`codes/` 下是独立小程序，可直接 `go run .`。
3. **带着问题学**：每章末尾有「想一想」和「练习」。先自己写，再对照正文。
4. **不要一次读完高级篇**：GMP、GC、逃逸分析建立在前面的语感上。

学习节奏参考（每天 1～2 小时）：

| 阶段 | 内容 | 建议时间 |
|------|------|----------|
| 入门 | 环境、类型、控制流、函数、切片/Map | 4～6 天 |
| 核心 | 指针、结构体、接口、错误、模块、标准库 | 6～8 天 |
| 并发 | goroutine、channel、select、sync、context | 5～7 天 |
| 进阶 | 泛型、反射、测试、IO、HTTP、工程结构 | 6～8 天 |
| 高级 | GMP、内存模型、GC、性能、陷阱 | 按需回看 |

## 约定

- 代码风格贴近 [Effective Go](https://go.dev/doc/effective_go) 与官方 blog，不为炫技牺牲可读性。
- 错误处理写完整：`if err != nil` 不会被省略成「此处略」。
- 并发示例会标出「会不会泄漏 goroutine」「会不会死锁」。
- 原理章用图和对照表，不堆源码行号当玄学。
