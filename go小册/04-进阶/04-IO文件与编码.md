# 04 · IO、文件与编码

服务进程大部分时间都在拷贝字节：文件、套接字、压缩、JSON。Go 用 `io.Reader`/`io.Writer` 把这些东西接成管道。这一章把「流式、缓冲、编码、资源关闭」写扎实。

---

## 1. 一切皆流

```go
func copyFile(dst, src string) error {
	in, err := os.Open(src)
	if err != nil {
		return err
	}
	defer in.Close()

	out, err := os.Create(dst)
	if err != nil {
		return err
	}
	defer func() {
		cerr := out.Close()
		if err == nil {
			err = cerr
		}
	}()

	_, err = io.Copy(out, in)
	return err
}
```

`io.Copy` 会用到 `WriterTo`/`ReaderFrom` 快路径（如 `*os.File` 之间可能用 `sendfile`）。自己写循环 `Read`/`Write` 前，先看能不能 `Copy`。

## 2. 缓冲

```go
r := bufio.NewReader(f)
line, err := r.ReadString('\n')

w := bufio.NewWriter(f)
defer w.Flush()
if _, err := w.WriteString("hi\n"); err != nil {
	return err
}
```

没 Flush 的 Writer 可能丢最后几 KB。`bufio.NewWriterSize` 在大批小写时很有用。

`bufio.Scanner` 默认单行上限约 64KB，超长行会 `ErrTooLong`。需要时 `scanner.Buffer` 加大。

## 3. 组合器

```go
r := io.LimitReader(req.Body, 1<<20)     // 最多 1MB
r = io.TeeReader(r, &logBuf)             // 边读边抄
mw := io.MultiWriter(os.Stdout, file)
pr, pw := io.Pipe()                      // 一端写一端读，跨 goroutine
```

`io.Pipe`：写端阻塞直到读端读走。一端出错要用 `CloseWithError` 通知另一端，否则会死锁。

```go
pr, pw := io.Pipe()
go func() {
	err := json.NewEncoder(pw).Encode(huge)
	pw.CloseWithError(err)
}()
_, err := io.Copy(dst, pr)
```

## 4. 文件与目录

```go
os.ReadFile / os.WriteFile / os.ReadDir
os.MkdirAll(path, 0o755)
os.Rename(old, new)          // 同盘上接近原子替换
os.Remove / os.RemoveAll
```

打开选项：`os.OpenFile(name, os.O_RDWR|os.O_CREATE|os.O_EXCL, 0o644)`。

可靠写配置的常用套路：写临时文件 → `Sync` → `Rename` 到目标，避免写到一半进程死掉留下半份 JSON。

路径：

```go
filepath.Join(dir, "a.txt")
filepath.Abs(p)
filepath.WalkDir(root, fn) // 1.16+，比 Walk 轻
```

处理用户传入路径时，用 `filepath.Clean` 并确保结果仍在根目录下，防止 `../../../etc/passwd` 这种路径穿越（服务端务必做）。

## 5. JSON 进阶

```go
enc := json.NewEncoder(w)
enc.SetIndent("", "  ")
enc.SetEscapeHTML(false) // 非 HTML 场景
if err := enc.Encode(v); err != nil {
	return err
}

dec := json.NewDecoder(r)
dec.UseNumber()
dec.DisallowUnknownFields()
```

流式数组：

```go
dec := json.NewDecoder(r)
tok, err := dec.Token() // [
for dec.More() {
	var item Item
	if err := dec.Decode(&item); err != nil {
		return err
	}
	// 处理 item
}
```

自定义：实现 `MarshalJSON`/`UnmarshalJSON`，或 `json.Marshaler`。时间、金额不要用 `float64`。

## 6. 其它编码

| 包 | 用途 |
|----|------|
| `encoding/csv` | 表格；注意 `LazyQuotes`、大文件用流 |
| `encoding/base64` | 邮件、JSON 里的二进制 |
| `encoding/hex` | 调试哈希 |
| `encoding/binary` | 固定宽度二进制协议，注意大小端 |
| `compress/gzip` | `gzip.NewWriter` 用完 Close 才会写尾部 |
| `crypto/sha256` | `io.Copy(h, r); h.Sum(nil)` |

```go
h := sha256.New()
if _, err := io.Copy(h, f); err != nil {
	return err
}
sum := hex.EncodeToString(h.Sum(nil))
```

## 7. 内存与大文件

- 不要对不可信输入 `ReadAll` 不设上限。
- 大文件哈希、拷贝用流。
- `mmap` 不在标准库，需要时再引入专门包，并搞懂生命周期。
- `bytes.Buffer` 会一直涨，循环里复用要 `Reset`，或上 `sync.Pool`。
