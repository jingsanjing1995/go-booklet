# 02 · 结构体与方法

结构体是把数据绑在一起的方式；方法是挂在类型上的函数。没有继承，复用靠**嵌入（embedding）**和接口。

---

## 1. 定义与字面量

```go
type User struct {
	ID    int64
	Name  string
	Email string
	age   int // 未导出，仅本包可见
}

u1 := User{ID: 1, Name: "Ada"}
u2 := User{1, "Ada", "ada@example.com", 0} // 按字段顺序，易碎，少用
u3 := User{}                               // 全零值
p := &User{Name: "Bob"}
```

推荐**键值字面量**。字段顺序一变，位置字面量就错。

空结构体 `struct{}` 不占空间，适合当集合：

```go
set := make(map[string]struct{})
set["a"] = struct{}{}
```

---

## 2. 字段、标签、可见性

```go
type Film struct {
	Title string `json:"title" db:"title"`
	Year  int    `json:"year,omitempty"`
	raw   []byte `json:"-"`
}
```

标签是给反射和第三方库看的字符串。`encoding/json`、ORM、校验库都靠它。标签里的空格、引号写错是运行时才发现的经典坑，写完用测试锁住。

未导出字段：外包看不到，JSON 默认也不导出。要跨包隐藏实现，这是正确手段。

## 3. 方法

```go
func (u User) DisplayName() string {
	if u.Name == "" {
		return "匿名"
	}
	return u.Name
}

func (u *User) Rename(name string) {
	u.Name = name
}
```

接收者名字用类型的一两个字母（`u`、`c`），不要用 `this`/`self`。

值接收者看到的是拷贝：在方法里改字段，外面不变。指针接收者共享同一份。

**nil 接收者也能调方法**（不会因为调用本身就 panic）：

```go
func (u *User) NameOrEmpty() string {
	if u == nil {
		return ""
	}
	return u.Name
}

var u *User
fmt.Println(u.NameOrEmpty()) // ""
```

这是实现「零值可用」接口的常用技巧，标准库里的 `(*os.File)(nil)` 讨论、`bytes.Buffer` 等都在利用零值。

## 4. 嵌入：组合，不是继承

```go
type Engine struct {
	Power int
}

func (e Engine) Start() { fmt.Println("vroom", e.Power) }

type Car struct {
	Engine // 匿名字段
	Brand  string
}

c := Car{Engine: Engine{Power: 200}, Brand: "X"}
c.Start()       // 提升：等于 c.Engine.Start()
fmt.Println(c.Power)
```

嵌入把**字段和方法提升**到外层。外层同名方法会**覆盖**提升来的方法（并不是多态重写，只是名字遮挡）。

嵌入接口：

```go
type ReadWriter struct {
	io.Reader
	io.Writer
}
```

`ReadWriter` 自动拥有 `Read`/`Write`，只要两个字段非 nil 且实现了对应接口。这是包装、装饰的基本手法。

**嵌入不是子类型**：`Car` 不能当 `Engine` 传。需要多态，用接口。

指针嵌入 vs 值嵌入：

```go
type Car struct {
	*Engine
}
```

外层零值时 `Engine` 是 nil，调用提升方法可能 panic。值嵌入更常见、更安全。

## 5. 构造函数与零值

Go 没有构造器关键字。约定：

```go
func NewUser(name string) (*User, error) {
	name = strings.TrimSpace(name)
	if name == "" {
		return nil, errors.New("empty name")
	}
	return &User{Name: name}, nil
}
```

- `NewXxx` 返回指针或值 + error。
- 必须初始化的不变量，放进 `New`，并把字段藏起来（未导出）用方法维护。
- 零值就能用的类型（`bytes.Buffer`、`sync.Mutex`）不必强迫 `New`。

---

## 6. 比较、拷贝、可变性

结构体可以 `==`，当且仅当所有字段可比较。含切片、map、函数字段则不能。

赋值是浅拷贝：

```go
a := User{Name: "Ada", Labels: []string{"x"}}
b := a
b.Labels[0] = "y" // a.Labels 也被改，因为切片共享
```

需要独立副本时，自己深拷贝切片/map 字段。

---

## 7. 小例子：带不变量的类型

```go
type Email struct {
	raw string
}

func ParseEmail(s string) (Email, error) {
	s = strings.TrimSpace(s)
	if !strings.Contains(s, "@") {
		return Email{}, fmt.Errorf("invalid email %q", s)
	}
	return Email{raw: s}, nil
}

func (e Email) String() string { return e.raw }
```

外包装不成非法 `Email`（除非用反射）。这比一堆散落的校验更稳。
