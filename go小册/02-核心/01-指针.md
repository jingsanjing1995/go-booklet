# 01 · 指针

Go 有指针，没有指针运算。你不能把 `p+1` 挪到下一个元素（那是 `unsafe` 的世界）。指针在这里只做一件事：**让调用方和被调用方看到同一块数据**。

---

## 1. 取址与解引用

```go
x := 10
p := &x     // *int，指向 x
fmt.Println(*p) // 10
*p = 20
fmt.Println(x)  // 20
```

```go
var p *int
fmt.Println(p == nil) // true
// *p = 1             // panic
```

零值是 `nil`。解引用 nil 会 panic。先判空，或保证构造完成后才用。

`new(T)` 分配一个 T 的零值并返回 `*T`：

```go
p := new(int) // *p == 0
```

结构体更常见的是复合字面量取址：

```go
u := &User{Name: "Ada"} // *User
```

---

## 2. 为什么要传指针

```go
type Counter struct{ N int }

func (c Counter) IncValue()  { c.N++ }       // 改的是副本
func (c *Counter) IncPtr()   { c.N++ }       // 改的是原值

func reset(c *Counter) {
	if c == nil {
		return
	}
	c.N = 0
}
```

传指针的三个动机：

1. **要改原值**
2. **避免拷贝大结构体**
3. **表达可选 / 缺失**：`*int` 可以是 nil，表示「没填」；`int` 的 0 分不清「没填」和「就是 0」

不要为了「看起来专业」给小结构体到处加指针。拷贝一个几个字的结构体往往比制造堆对象更便宜。逃逸分析见高级篇。

---

## 3. 指针、切片、map 不要混为一谈

| 你想改什么 | 怎么传 |
|------------|--------|
| 结构体字段 | `*T` |
| 切片里的元素 | 传切片即可（共享数组） |
| 切片本身（len/cap/换数组） | 返回新切片，或 `*[]T` |
| map 的内容 | 传 map 即可 |
| 让变量指向另一个 map | 需要 `*map[K]V`（很少见） |

```go
func appendOne(s []int) []int {
	return append(s, 1)
}
```

切片头是值，指针感来自「头里的 ptr」。这不是 `*[]int`，初学时最容易绕晕。

---

## 4. 指针的指针、指向切片元素

```go
var pp **int // 极少在业务里出现
```

切片元素可以取址：

```go
s := []int{1, 2, 3}
p := &s[1]
*p = 9 // s 变成 [1 9 3]
```

**append 一旦换了底层数组，旧指针就指向被抛弃的数组。** 不要在可能扩容的切片上长期握着元素指针。

map 的值不能取址，前面已经说过。

---

## 5. 接收者：值 vs 指针（先记结论）

```go
func (u User) Name() string    // 值接收者：方法里改 u 不影响外
func (u *User) SetName(s string) // 指针接收者
```

经验法则：

- 方法要改接收者 → 指针。
- 结构体较大 → 指针。
- 有的方法已是指针接收者 → 同类型其他方法也用指针，保持一致。
- 类型是 map/slice/chan 这种引用感很强的 → 常用值接收者（它本身已是引用头）。
- 需要类型同时当接口用时，指针接收者的方法集 **不包含** 在值类型里。细节见接口章。

Go 会自动取址/解引用来匹配方法调用：

```go
u := User{}
u.SetName("Ada")  // 编译器写成 (&u).SetName
p := &u
_ = p.Name()      // 编译器写成 (*p).Name
```

对 **不可寻址** 的值不行：`User{}.SetName("x")` 编不过，因为字面量不能取址。

---

## 6. 返回局部变量的指针是合法的

```go
func newUser(name string) *User {
	u := User{Name: name}
	return &u // u 逃逸到堆，不会变成悬空指针
}
```

没有「返回局部变量指针就是未定义行为」。编译器通过逃逸分析决定栈还是堆。你仍然要避免返回指向循环可复用 buffer 的指针。

---

## 7. 可选值的两种建模

```go
type Patch struct {
	Name *string
	Age  *int
}

func strPtr(s string) *string { return &s }
```

或者用 `sql.NullString`、自己的 `Optional[T]`（泛型）。别用魔法数字 `-1` 表示「没设置」，除非协议已经如此。
