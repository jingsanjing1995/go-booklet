## 2. 格式化、日志、时间

**fmt**：`Print` / `Sprint` / `Errorf`。调试用 `%#v`（Go 语法）、`%T`（类型）、`%q`（带引号）。

**log**：简单足够。生产更推荐 `log/slog`（1.21+）：

```go
slog.Info("upload ok", "file", name, "size", n)
slog.Error("open failed", "err", err)
```

JSON handler 方便收集：`slog.New(slog.NewJSONHandler(os.Stdout, nil))`。

**time**：

```go
now := time.Now()
d := 500 * time.Millisecond
t, err := time.Parse(time.RFC3339, "2026-10-10T12:00:00Z")
ctx, cancel := context.WithTimeout(ctx, 2*time.Second)
```

解析必须用**参考时间** `Mon Jan 2 15:04:05 MST 2006`（记忆：1 2 3 4 5 6）。不要用 `YYYY` 这种占位。

定时器：`time.After`、`time.NewTimer`、`time.NewTicker`。`Ticker` 用完 `Stop`，循环里对 `After` 要小心（每次分配，且旧 timer 在超时前会占着内存）。

## 3. IO 三件套

```text
io.Reader / io.Writer / io.Closer
        ↑
   bufio.Reader/Writer   （缓冲）
        ↑
   os.File / bytes.Buffer / strings.Reader / net.Conn
```

常用函数：

```go
io.Copy(dst, src)
io.ReadAll(r)           // 注意大文件内存
io.LimitReader(r, 1<<20)
io.MultiWriter(w1, w2)
```

`os`：`Open` `Create` `ReadFile` `WriteFile` `MkdirAll` `Getenv` `Args`。

```go
data, err := os.ReadFile("config.json")
if err != nil {
	return err
}
if err := os.WriteFile("out.txt", data, 0o644); err != nil {
	return err
}
```

权限用八进制 `0o644`。Windows 上部分权限位被忽略。

## 4. JSON 与其它编码

```go
type User struct {
	ID   int64  `json:"id"`
	Name string `json:"name"`
}

b, err := json.Marshal(u)
err = json.Unmarshal(b, &u)

dec := json.NewDecoder(resp.Body)
dec.DisallowUnknownFields()
err = dec.Decode(&u)
```

坑：

- 数字到 `interface{}` 会变成 `float64`。
- `[]byte` 字段默认 base64。
- `time.Time` 默认 RFC3339。
- nil 切片 → `null`，空切片 → `[]`。
- 未导出字段不参与。

流式用 `Encoder`/`Decoder`，不要先 `ReadAll` 再 Unmarshal 超大 JSON。

其它：`encoding/base64`、`encoding/hex`、`encoding/csv`、`encoding/xml`、`encoding/binary`。

## 5. 字符串、数字、路径、正则

| 包 | 场景 |
|----|------|
| `strings` / `bytes` | 查找、切分、替换、Builder |


## 6. HTTP 最小可用

服务端：

```go
mux := http.NewServeMux()
mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
	w.WriteHeader(http.StatusOK)
	_, _ = w.Write([]byte("ok"))
})
s := &http.Server{Addr: ":8080", Handler: mux}
log.Fatal(s.ListenAndServe())
```

Go 1.22+ 的 ServeMux 支持方法和路径模式：`GET /users/{id}`。

客户端：

```go
req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
if err != nil {
	return err
}
resp, err := http.DefaultClient.Do(req)
if err != nil {
	return err
}
defer resp.Body.Close()
```

**永远 Close Body**，否则连接不能复用。进阶篇会把超时、中间件、优雅退出写完整。

## 7. context、sort、math、flag、sync

- `context`：超时和取消，并发篇专讲。现在先记住所有会 I/O 的函数第一个参数最好是 `ctx`。
- `slices` / `maps`（1.21+）：排序、克隆、删、收集。旧代码会看到 `sort.Slice`。
- `math` / `math/rand/v2`：随机用 `rand/v2`（1.22+），不要用旧 `math/rand` 全局源写并发。
- `flag`：简单 CLI。复杂工具再考虑外部库。
- `sync`：Mutex、WaitGroup，并发篇。
- `reflect`：最后手段，进阶篇。
