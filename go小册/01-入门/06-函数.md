# 06 · 函数

函数是 Go 的基本拼装单位。没有类，行为就落在函数和方法上。这一章把多返回值、命名返回值、可变参数、闭包和延迟调用的函数侧讲清楚；方法留到结构体章。

---

## 1. 签名

```go
func Add(a, b int) int {
	return a + b
}

func Div(a, b int) (int, error) {
	if b == 0 {
		return 0, errors.New("division by zero")
	}
	return a / b, nil
}
```

要点：

- 参数类型相同时可以只写一次：`a, b int`。
- 多返回值是语言特性，不是元组语法糖；调用方必须接，或用 `_` 丢掉。
- **最后一个返回值常常是 `error`**，成功时返回 `nil`。

没有默认参数，没有函数重载。需要可选配置时，用：

- 多个函数：`New` / `NewWithTimeout`
- 选项函数（functional options）
- 配置结构体

## 2. 命名返回值

```go
func SplitHostPort(hp string) (host string, port string, err error) {
	parts := strings.Split(hp, ":")
	if len(parts) != 2 {
		err = fmt.Errorf("invalid: %q", hp)
		return // 返回当前 host/port/err
	}
	host, port = parts[0], parts[1]
	return
}
```

适用：返回值有清楚含义、函数不长。  
滥用：函数很长时，裸 `return` 会让读者去猜当前值。

注意阴影：

```go
func bad() (err error) {
	if err := do(); err != nil { // 内层新 err
		return // 返回的是外层零值 nil！编译器有时会警告
	}
	return
}
```

命名返回值在 `defer` 里可以被修改，这是「defer 里改 err」模式的基础，见核心篇。

## 3. 可变参数

```go
func Sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

Sum(1, 2, 3)
Sum(append([]int{1}, 2, 3)...) // 切片打散
```

`nums` 在函数里就是 `[]int`。只能有一个可变参数，且必须在最后。

`fmt.Println(a ...any)`、`append` 都是这个机制。

---

## 4. 函数是值

```go
var op func(int, int) int
op = Add
fmt.Println(op(1, 2))

func apply(n int, f func(int) int) int {
	return f(n)
}

apply(3, func(x int) int { return x * x })
```

函数类型包含参数和返回值。签名不同就不能赋值。

零值是 `nil`，调用 `nil` 函数会 panic。当作字段或回调时先判空。

## 5. 闭包与变量捕获

```go
func adder(base int) func(int) int {
	return func(n int) int {
		base += n
		return base
	}
}

a := adder(10)
fmt.Println(a(1)) // 11
fmt.Println(a(2)) // 13
```

闭包会把 `base` **引用**带走，`adder` 返回后 `base` 仍活着（通常逃逸到堆上）。

循环里起 goroutine 时，1.22 之前要特别小心循环变量；1.22 起每轮新变量。仍然推荐把需要的值当参数传进去，意图更明确：

```go
for i := 0; i < 3; i++ {
	go func(id int) {
		fmt.Println(id)
	}(i)
}
```

## 6. defer 在函数里的行为（先记使用层）

```go
func read(path string) ([]byte, error) {
	f, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer f.Close()
	return io.ReadAll(f)
}
```

- `defer` 的实参立刻求值，函数调用本身推迟到外层函数返回时。
- 多个 defer **后进先出**。
- `defer` 在循环里会堆积，文件很多时优先在循环内包一层函数，或小心关闭。

更完整的 panic/recover 见核心篇。这里只要养成「拿到资源就 defer 释放」。

## 7. 递归、init 级函数与 main

Go 有递归，没有尾递归保证。深递归可能涨栈（栈是可增长的，但仍可能耗尽内存）。能改循环就改循环。

`main` 和 `init` 不能有参数和返回值，也不能是方法。

匿名函数立即执行：

```go
func() {
	fmt.Println("IIFE")
}()
```

少用。Go 没有块级私有的强需求时，直接写普通函数更清晰。

## 8. 错误处理的函数风格

```go
func (c *Client) User(ctx context.Context, id string) (User, error) {
	if id == "" {
		return User{}, errors.New("empty id")
	}
	raw, err := c.get(ctx, "/users/"+id)
	if err != nil {
		return User{}, fmt.Errorf("get user %s: %w", id, err)
	}
	var u User
	if err := json.Unmarshal(raw, &u); err != nil {
		return User{}, fmt.Errorf("decode user %s: %w", id, err)
	}
	return u, nil
}
```

模式：校验 → 调用 → 包装错误 → 返回零值 + err。成功路径保持较浅的缩进。这就是「啰嗦但直」的 Go 函数。
