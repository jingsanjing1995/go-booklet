# 05 · 运算符与控制流

Go 的控制流刻意很少：`if`、`for`、`switch`、`goto`（几乎不用）。没有 `while`，没有三元运算符。少分支语法，是为了让所有人用同一种方式写分支。

---

## 1. 运算符速查

算术：`+ - * / %`，整数除法截断向零，`(-3)/2 == -1`。  
位运算：`& | ^ &^ << >>`，`^` 既是按位异或也是按位取反（一元）。  
比较：`== != < <= > >=`，切片、map、函数不能比较（只能和 `nil` 比）。  
逻辑：`&& || !`，短路求值。  
取址 / 解引用：`&` `*`。  
接收：`<-ch`。

赋值：

```go
a += 1
b &^= 0x04 // 清掉某些位，等价于 b = b &^ mask
```

自增只有语句，不是表达式：

```go
i++
// j := i++  // 非法
```

优先级不必死记，不确定就加括号。值得小心的是位移的类型：右边会转换成无符号，负数位移是编译错误（常量）或运行时 panic（变量）。

---

## 2. if：初始化语句是一等公民

```go
if err != nil {
	return err
}

if n, err := strconv.Atoi(s); err != nil {
	return err
} else if n < 0 {
	return fmt.Errorf("negative: %d", n)
} else {
	use(n)
}
```

`if` 前面的短声明作用域只到 `if/else` 结束。这正是处理 `error` 的惯用写法。

Go 社区更喜欢**提前返回**，少嵌套：

```go
func fetch(id string) (Item, error) {
	if id == "" {
		return Item{}, errors.New("empty id")
	}
	item, err := db.Get(id)
	if err != nil {
		return Item{}, err
	}
	return item, nil
}
```

没有三元。需要表达式时写函数，或老老实实 `if`。

---

## 3. for：唯一的循环

三种形态，一种关键字。

```go
// 经典
for i := 0; i < 10; i++ {
}

// 当 while
for !done {
}

// 无限
for {
	if cond {
		break
	}
}
```

`range`：

```go
for i, v := range slice { // i 索引，v 是拷贝
}

for k, v := range m { // map 迭代顺序随机
}

for i, r := range s { // 字符串：i 是字节下标，r 是 rune
}

for v := range ch { // 读 channel，关闭后循环结束
}
```

Go 1.22 起可以直接：

```go
for i := range 5 { // 0,1,2,3,4
}
```

1.22 还修了一个老坑：**循环变量每轮是新变量**。以前在闭包里直接捕获 `i` 会「全是最后一次」；现在按轮次分别捕获。写新代码可以按「每轮独立」来想，维护老版本代码仍要小心。

`v` 是元素的**拷贝**。改 `v` 不会改切片里的元素；要改原值请用下标：

```go
for i := range users {
	users[i].Name = strings.TrimSpace(users[i].Name)
}
```

`break` / `continue` 可以带标签，用来跳出外层循环：

```go
Outer:
	for i := 0; i < n; i++ {
		for _, c := range line {
			if c == '#' {
				break Outer
			}
		}
	}
```

标签少用，嵌套太深说明该拆函数。

## 4. switch：默认 break，可以没有条件

```go
switch day {
case 1, 2, 3, 4, 5:
	fmt.Println("weekday")
case 6, 7:
	fmt.Println("weekend")
default:
	fmt.Println("invalid")
}
```

和 C 不同：**匹配后自动结束，不会贯穿**。要贯穿写 `fallthrough`（很少需要，它会进入**下一个 case 体**，不再判断条件）。

无条件 switch 就是更清晰的 if-else 链：

```go
switch {
case n < 0:
	fmt.Println("neg")
case n == 0:
	fmt.Println("zero")
default:
	fmt.Println("pos")
}
```

带初始化：

```go
switch n, err := strconv.Atoi(s); {
case err != nil:
	return err
case n < 0:
	return fmt.Errorf("neg")
}
```

类型 switch 见接口章：`switch x := v.(type)`。

---

## 5. goto、break 标签：知道即可

`goto` 只能跳到同函数内的标签，不能跳过变量声明。几乎只在生成代码或极致性能的状态机里出现。手写业务请用函数和循环。

---

## 6. 几个会咬人的点

**切片、map、函数不可比较**（除了和 `nil`）。结构体能否 `==` 取决于所有字段是否可比较。含切片字段的结构体就不能当 map 的键。

**`range` map 顺序每次都可能不同**。测试里断言「第一个键是 x」会闪烁失败。需要稳定顺序就取出 key 排序。

**空 switch / 空 if 条件必须是 bool**。`if err` 非法，必须 `if err != nil`。
