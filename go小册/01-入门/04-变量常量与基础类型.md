# 04 · 变量、常量与基础类型

Go 的类型系统偏「显式、无隐式转换」。先把变量怎么声明、零值是什么、整数家族如何换算搞清楚，后面指针和接口才不会飘。

---

## 1. 四种声明姿势

```go
var name string                 // 零值 ""
var age int = 20                // 显式类型 + 初值
var city = "Hangzhou"           // 类型推断
country := "CN"                 // 短声明，只能在函数内
```

短声明的细节：

```go
func demo() {
	x := 1
	x, y := 2, 3 // x 是赋值，y 是新变量；至少要有一个新名字
	fmt.Println(x, y)
}
```

`:=` 左边至少出现一个**当前作用域的新变量**。外层已有同名变量时，`:=` 会在内层**再声明一个**，这是阴影（shadow），非常常见的坑：

```go
n := 1
if true {
	n := 2          // 新的 n，外层仍是 1
	fmt.Println(n)  // 2
}
fmt.Println(n)      // 1
```

## 2. 零值：设计，不是缺陷

未赋初值的变量是该类型的**零值**，不是未定义。

| 类型 | 零值 |
|------|------|
| `bool` | `false` |
| `int` / `int64` / `uint` ... | `0` |
| `float32` / `float64` | `0` |
| `complex64` / `complex128` | `0+0i` |
| `string` | `""` |
| 指针、接口、切片、map、channel、函数 | `nil` |
| 数组、结构体 | 每个元素/字段的零值 |

零值能用的例子：`bytes.Buffer`、`sync.Mutex`、`sync.WaitGroup`。  
零值不能写的例子：`nil` map 读取返回零值，**赋值会 panic**。

养成习惯：遇到新类型先问「零值语义是什么」。

## 3. 基础类型一览

### 3.1 布尔

只有 `true` / `false`。整数不能当布尔，`if 1` 编不过。

### 3.2 整数

有符号：`int8` `int16` `int32` `int64` `int`  
无符号：`uint8` `uint16` `uint32` `uint64` `uint` `uintptr`  
别名：`byte` = `uint8`，`rune` = `int32`（Unicode 码点）

`int` / `uint` 的宽度等于当前架构（64 位机上是 64 位）。**写协议、文件、哈希时用固定宽度**（`int64`、`uint32`），不要用 `int`。

没有隐式转换：

```go
var a int32 = 1
var b int64 = 2
// c := a + b   // 编译错误
c := int64(a) + b
```

溢出不会 panic，按位宽回绕（wrap around）。需要检查时自己写，或用 `math` 包的辅助函数。

### 3.3 浮点与复数

日常用 `float64`。比较相等要用误差，不要 `==`。  
复数：`complex128`，`real(z)` / `imag(z)`。一般业务用得少。

### 3.4 字符串

不可变字节序列，通常按 UTF-8 解释。下一章会专门讲 `[]byte` 和 `rune`。这里先记住：

```go
s := "Go小册"
fmt.Println(len(s))        // 字节数，不是「字符数」
fmt.Println(utf8.RuneCountInString(s))
```

## 4. 常量与 iota

常量在编译期确定，可以是布尔、数字、字符串（以及某些表达式）。

```go
const Pi = 3.14159          // 无类型常量
const MaxRetry int = 3      // 有类型常量

const (
	StatusOK = 200
	StatusNotFound = 404
)
```

**无类型常量**更灵活：`Pi` 可以赋给 `float32` 或 `float64`，只要不溢出。一旦写成 `const Pi float64 = ...`，就不能直接给 `float32`。

`iota` 是常量组里的计数器，从 0 开始，每遇到一个 const 规格加 1：

```go
const (
	_  = iota // 丢掉 0
	KB = 1 << (10 * iota) // 1 << 10
	MB                    // 1 << 20
	GB                    // 1 << 30
)

const (
	FlagRead  = 1 << iota // 1
	FlagWrite             // 2
	FlagExec              // 4
)
```

Go 没有 `enum` 关键字。常用模式：

```go
type Color int

const (
	ColorUnknown Color = iota
	ColorRed
	ColorBlue
)

func (c Color) String() string {
	switch c {
	case ColorRed:
		return "red"
	case ColorBlue:
		return "blue"
	default:
		return "unknown"
	}
}
```

注意：这只是带名字的整数，编译器**不会**阻止 `Color(99)`。需要严格枚举时自己校验。

## 5. 类型定义 vs 类型别名

```go
type UserID int     // 新类型，与 int 不能直接运算
type ID = int       // 别名，完全就是 int
```

```go
var u UserID = 1
var n int = 2
// _ = u + n        // 错
_ = int(u) + n      // 显式转换
```

给已有类型加方法，必须用**类型定义**（`type UserID int`），不能给别名或预声明类型直接加。这是自定义 `String()`、约束 ID 混用的常规手段。

## 6. 转换、断言，先分清

```go
var x int = 65
s := string(x) // "A" —— 把 x 当 rune，不是 strconv
b := []byte("hi")
t := string(b) // 按字节复制成字符串
```

数字和字符串之间请用 `strconv`：

```go
n, err := strconv.Atoi("42")
s := strconv.Itoa(42)
```

`.(T)` 是**类型断言**，只用于接口，不是普通类型转换。见核心篇「接口」。

## 7. 新内建函数（1.21+）值得知道

```go
a, b := 3, 5
fmt.Println(min(a, b), max(a, b))

s := []int{1, 2, 3}
clear(s) // 元素置零，len 不变
m := map[string]int{"a": 1}
clear(m) // 删光所有键
```

`min`/`max` 对整数、浮点、字符串都能用（同类型）。
