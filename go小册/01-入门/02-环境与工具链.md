# 02 · 环境与工具链

Go 的工具链本身就是学习材料。装好之后，你每天用的几乎就是：`go run`、`go build`、`go test`、`go mod`、`go fmt`、`go vet`。

---

## 1. 安装与验证

推荐从 [https://go.dev/dl/](https://go.dev/dl/) 安装官方发行版，或用系统包管理器（注意版本别太旧）。

```bash
go version
go env GOPATH GOROOT GOPROXY GO111MODULE
```

关键环境变量：

| 变量 | 含义 | 建议 |
|------|------|------|
| `GOROOT` | 安装目录 | 一般不用改 |
| `GOPATH` | 工作区、模块缓存、二进制安装位置 | 默认 `~/go` 即可 |
| `GOPROXY` | 模块下载代理 | 国内常用 `https://goproxy.cn,direct` |
| `GOSUMDB` | 校验和数据库 | 保持默认，勿随意关闭 |
| `GO111MODULE` | 模块模式 | 现代 Go 默认 on，不必设 |

配置代理（按需）：

```bash
go env -w GOPROXY=https://goproxy.cn,direct
```

编辑器：VS Code / Cursor 装官方 **Go** 扩展，保存时 `gofmt` 或 `goimports`。格式化不要关。

## 2. 模块是现在的默认世界

一个目录里有 `go.mod`，它就是一个模块。模块名通常是仓库路径：

```bash
mkdir hello && cd hello
go mod init example.com/hello
```

生成的 `go.mod` 类似：

```go
module example.com/hello

go 1.22
```

之后：

```bash
go get github.com/some/lib@v1.2.3   # 添加依赖
go get ./...                        # 按 import 补齐
go mod tidy                         # 删掉没用的、补上漏的
go list -m all                      # 看依赖图
```

`go.sum` 记录校验和，**要提交到 git**。它不是锁文件的全部语义，但能保证下到的内容没被篡改。

工作区（workspace，`go.work`）适合本地同时改多个模块，入门阶段可以先不碰。

## 3. 每天会用到的命令

```bash
go run .                 # 编译到临时目录并执行
go build -o bin/app .    # 产出二进制
go test ./...            # 递归跑测试
go test -race ./...      # 打开竞争检测
go fmt ./...             # 格式化
go vet ./...             # 静态检查（编译器的朋友）
go doc fmt.Println       # 看文档
go install example.com/cmd/foo@latest
```

交叉编译：

```bash
GOOS=linux GOARCH=arm64 CGO_ENABLED=0 go build -o app-linux-arm64 .
```

`CGO_ENABLED=0` 能得到纯 Go 静态二进制，容器里很好用；一旦用了 cgo，交叉和镜像会变复杂。

常用构建参数：

```bash
go build -ldflags "-s -w" -trimpath -o app .
```

- `-s -w`：去掉符号表和 DWARF，体积更小（调试变难）。
- `-trimpath`：二进制里不嵌入本机绝对路径，便于可复现构建。

## 4. 工作目录长什么样

入门期一个模块足够：

```text
hello/
  go.mod
  main.go
```

稍大一点：

```text
hello/
  go.mod
  cmd/hello/main.go      # 程序入口
  internal/greet/greet.go
  internal/greet/greet_test.go
```

`internal/` 是语言级约定：只有本模块（或父目录的模块）能 import 它，外部模块编译期就会失败。这是封装边界，不是礼貌约定。

`cmd/` 下放多个可执行入口，很常见：`cmd/server`、`cmd/worker`。

## 5. 文档、测试、竞态，三位一体

```bash
go doc -all example.com/hello/internal/greet
go test -v -count=1 ./...
go test -race ./...
```

- `-count=1` 关掉测试缓存，改环境变量或依赖时间的测试时很有用。
- `-race` 会让程序变慢，但能抓住「两个 goroutine 没同步就写同一块内存」。并发章之后请养成习惯。

`go test` 还能出覆盖率：

```bash
go test -coverprofile=cover.out ./...
go tool cover -html=cover.out
```

## 6. 版本、工具与「装到哪」

`go install` 把二进制放进 `$(go env GOPATH)/bin`，把该目录加进 `PATH`。

指定工具版本（Go 1.24+ 更推荐在模块里管理工具依赖，入门先记住）：

```bash
go install golang.org/x/tools/cmd/goimports@latest
```

`gofmt` 只管格式；`goimports` 还会整理 import。编辑器保存时跑其中之一即可。

## 7. 常见安装问题

| 现象 | 常见原因 | 处理 |
|------|----------|------|
| `command not found: go` | PATH 没包含安装目录 | 重新打开终端，或把 `.../go/bin` 加进 PATH |
| 下载依赖极慢 / timeout | 没设代理 | `go env -w GOPROXY=...` |
| `package xxx is not in std` | 模块外乱放，或 import 路径写错 | 确认在 `go.mod` 所在树里执行 |
| IDE 红线但命令行正常 | 扩展选错了 Go 版本 | 看 `go env GOROOT`，在设置里对齐 |
